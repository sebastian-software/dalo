Dalo homepage concepts

Six fundamentally different light directions for dalo.sh. Each one is a self-contained page; the shared brief lives in BRIEF.md.

  • 01

    Broadsheet

    An editorial newspaper front page: masthead, lead story, figures, letters, classifieds.

  • 02

    Blueprint

    An engineering drawing set with a dimensioned pipeline schematic and title block.

  • 03

    dalo(1)

    The homepage is the manual page, with a live less-style status bar.

  • 04

    Soft bento

    Warm pastel product page; every tile is a small mini UI with real output.

  • 05

    Swiss

    International Typographic Style: a visible grid, huge type, one signal color.

  • 06

    Commit graph

    The page as a git history, from local experiment to team standard.
