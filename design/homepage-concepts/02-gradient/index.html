Fifteen deterministic security rules run locally on every skill. Catalog skills also wait for your explicit approval before Dalo links them.

Safe by default

Only touches what it owns.

Dalo never overwrites your files or folders. Add --dry-run to any command and see every change first.

Dalo may manage what it owns. It does not take ownership by surprise.

Three commands to a shared set.

After install, run dalo init once. Every step takes --dry-run.

  1. 1Link your agent
    dalo target link claude
  2. 2Add your team's repo
    dalo source add company git@github.com:acme/agent-skills.git
  3. 3Sync
    dalo sync
