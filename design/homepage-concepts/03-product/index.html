Your team’s agent skills, versioned like code.

Dalo keeps your skills in Git, reviews each one before it reaches an agent, and links one pinned set into every agent’s folder — the same on every machine.

1One source of truth

One pinned set. Every agent, every machine.

Skills live in your team’s Git repo. Dalo resolves them to exact commits and links the same set into every agent you run. Local overrides win, and whatever they shadow stays visible.

How resolution works
lock.toml~/.dalo
1schema_version = 6
2
3[[sources]]
4id = "company"
5kind = "team"
6commit = "4e7a1c9d2f8b06e15a3c4…"pinned
7
8[[active_skills]]
9source_ref = "company:incident-review"
10slot_name = "incident-review"
2Reviewed

Nothing reaches an agent unreviewed.

A local security preflight checks every skill. Catalog skills wait for an explicit approval, bound to their exact content. A passing check is not a guarantee, so the decision stays yours.

3Safe by default

Dalo only touches what it owns.

Your own folders are never overwritten, and --dry-run shows every link before anything changes. A dirty checkout blocks the sync instead of losing your edits.

>_Quickstart

Three steps to a shared set.

Connect your agents, add the team repository, sync. Just git on your PATH, no daemon.

Also via curl, npx, cargo and mise — install guide.

zsh~
1Connect your agents
$ dalo init
$ dalo target link claude
2Add your team’s skills
$ dalo source add company git@github.com:acme/agent-skills.git
3Link the approved set
$ dalo sync
synced: 2 skills across 1 target (2 created)

Give every agent the same reviewed skills.

Open source under MIT or Apache-2.0. Install it once, then let every machine resolve the same set.
