One source of truth. Your skills live in a Git repo. Dalo pins the exact commit and links the same approved set into Codex, Claude Code and every other agent, on every machine. How sources work →

Reviewed before it reaches an agent. New skills wait for an explicit approval, and a local security preflight of 15 deterministic rules runs first. A clean result is not a guarantee, and Dalo says so. Security model →

Safe by default. Dalo only replaces links it owns. Your own folders are never overwritten: a clash is reported as blocked, and --dry-run shows every change first. Read the spec →

The core rule
Dalo may manage what it owns. It does not take ownership by surprise.

Sync removes only links it owns, leaves your folders alone, and stops at a dirty checkout instead of losing edits.
