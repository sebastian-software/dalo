the gates

Reviewed before it reaches an agent.

A local security preflight and your explicit approval gate every skill. Until both pass, nothing is linked.

Catalog skill sebastian:effective-web selected · pinned
Security preflight 15 deterministic rules, run locally. passed
Your approval Explicit, recorded in your store. pending
Agent folder ~/.claude/skills not linked yet 
$ dalo sync
pending approval: sebastian:effective-web (run: dalo approve skill sebastian:effective-web)

High and critical findings block until you explicitly accept the risk. A passing preflight is a gate, not a guarantee.

the output

Safe by default.

Dalo only touches the links it owns. It never overwrites your files, and --dry-run shows every change first.

A team checkout with uncommitted edits blocks the refresh instead of losing your work.

quickstart

Running in three steps.

One Rust binary, no daemon, just git on your PATH. For macOS and Linux.

~/work
# 1 · set up and link an agent
$ dalo init
$ dalo target link codex

# 2 · add your team's skills
$ dalo source add company git@github.com:acme/agent-skills.git

# 3 · sync
$ dalo sync
applied  create     target[codex]:/incident-review -> store:/sources/company/checkout/skills/incident-review
applied  create     target[codex]:/release-notes -> store:/sources/company/checkout/skills/release-notes
synced: 2 skills across 1 target (2 created)
security preflight: deterministic checks only

One reviewed set. Every agent.
