Read the docs

01

One source of truth.

Skills live in Git. Dalo resolves one pinned set from all your sources, with the same result on every machine. Name conflicts follow source priority, never chance.

Lower priority number wins; the rest are reported as shadowed.

02

Reviewed before it lands.

Fifteen deterministic rules run locally before any link is created. High and critical findings block until you accept the risk. Catalog skills wait for your explicit approval.

A gate, not a guarantee: you stay the reviewer.

03

Safe by default.

Dalo links only what it owns. It never overwrites your files or folders, and --dry-run shows every change before it happens.

Dirty team checkouts block a refresh instead of losing your edits.

Install guide
Quickstart~/work
  1. 1Link your agent
    $ dalo init && dalo target link claude
  2. 2Add your team's repository
    $ dalo source add company git@github.com:acme/agent-skills.git
  3. 3Sync
    $ dalo sync
