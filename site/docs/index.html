Dalo documentation

Everything the CLI can do today. The installation guide lives at install.md, the release history in the changelog.

  • Getting started Install Dalo, link an agent, add sources, and reach a first synced skill set.
  • Team repository Publish a team source: pin external catalogs, advance a pin, and onboard a teammate.
  • Command reference Every command, flag, config file, JSON report, and diagnostic code.
  • Compatibility What is stable in 1.x, what is experimental, and how breaking changes are announced.
  • Upgrading to 1.0 Move a 0.x store to 1.0: what the first sync migrates, which spellings were removed, and how to recover.
  • Plugins Portable plugin packages, their typed tools and hooks, and the separate approvals each one needs.
  • Agent integration Supported agents, their skill directories, and how instruction packs are written.
  • Dalo in CI Run a reproducible, non-interactive sync in a pipeline.
  • Troubleshooting Resolver, doctor, and security findings with the command that clears each one.
  • Security overview Trust boundaries, what the preflight blocks, the approval model, and the stated limits.
  • Uninstall Remove targets, autosync, the store, and the binary.
  • Comparison How Dalo compares with agentfiles and Vercel's skills CLI, and when each one is the better fit.
